Cat Loading

Upgrade your loading display to make the user experience more enjoyable with a cat-themed loading screen

Overview

Cat Loading is a delightful Odoo module that transforms the mundane loading experience into something enjoyable. By replacing Odoo's standard loading indicator with a playful cat-themed animation, this module adds a touch of fun to the interface while users wait for processes to complete.

Whether your users are loading reports, processing data, or navigating between modules, they'll be greeted with charming cat animations that make waiting times feel shorter and more pleasant.
