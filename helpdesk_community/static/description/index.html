Key features

Ticket management

Create, assign, prioritize and resolve tickets with full chatter history and automatic ticket numbering.

Kanban pipeline

Drag tickets across stages: New → In Progress → Resolved → Closed. Customizable to your workflow.

Teams & assignment

Group agents into teams. Assignment policies: manual, round-robin, least-loaded, or random.

Categories & priorities

Classify tickets by type or product. Set priority levels for fast triage and filtering.

Customer portal

Portal users can submit, view and track their own tickets without an internal agent login.

Email notifications

Automatic email alerts on assignment, stage changes, and ticket resolution using Odoo mail templates.

Search & filters

Filter and group tickets by stage, team, priority, assignee, category, or creation date.

Access control

Three roles: User, Team Leader, Manager. Portal access for customers. Enforced by record rules.

Is this module really free?

Yes. Licensed under LGPL-3, the same permissive license as Odoo Community itself. No paywalls, no premium features, no subscription required.

Does it work with Odoo Enterprise?

Yes. The module is compatible with both Community and Enterprise editions. No Enterprise modules are required as dependencies.

How do I upgrade from one version to another?

Installation

Install the module from Apps. Dependencies (base, mail, portal, web) install automatically.
2
Default stages (New → In Progress → Resolved → Closed) are created on install.
3
Create teams, add members, set assignment policies and configure categories.
4
Configure email — optionally set up Odoo's outgoing mail server for email notifications.
5
Grant portal access to customers who should submit and track tickets.
